# CARMA-Affect

**组合条件效用学习与风险受控的多模态情感历史利用**

> 状态：**PROVISIONAL / 研究候选方案**
>
> 更新时间：2026-08-07
> 当前证据：已完成方法设计与合成环境 sanity check，**尚未完成真实数据主实验**。

CARMA-Affect研究多模态对话情感识别中的一个风险决策问题：在测试期不访问当前或历史真实情感标签的条件下，模型能否判断一组严格过去的同说话人历史会改善还是损害当前情感预测，并在伤害风险不可接受时回退到只看当前信息的模型？

## 核心创新

1. **组合条件边际效用**：不再独立判断每条历史是否有用，而是学习候选历史在已选集合条件下的增量价值，显式建模历史之间的互补、冗余与冲突。
2. **策略级风险校准**：以current-only为安全基准，在独立校准集上检验完整自适应选择策略的excess risk，并冻结满足风险约束的策略阈值。
3. **选择性回退**：当所有候选历史的安全下置信界均不大于零时，令所选集合为空并回退到current-only。

## 方法框架

![CARMA-Affect方法框架](assets/carma-affect-method-framework.png)

方法由三部分组成：

- **测试期推理**：编码当前多模态话语和严格过去的同说话人历史，预测条件边际效用分布，逐步进行安全边际选择。
- **训练与独立校准**：在train内部进行嵌套cross-fitting，利用折外预测损失差生成效用标签；在独立calibration split上冻结策略阈值。
- **实验验证**：测量自然负迁移、历史交互、历史特异性、风险-覆盖率、状态恢复和分布变化。

## 当前结果：仅合成验证

合成环境预先写入状态切换、失配历史和历史冗余，因此下列结果只能说明方法逻辑可运行，不能证明真实情感数据中存在相同机制。

| 虚拟策略 | 平均收益 | 伤害比例 | 使用覆盖率 | 平均历史数 |
|---|---:|---:|---:|---:|
| 全部8条历史 | -2.141 | 71.8% | 100.0% | 8.00 |
| Recent-4 | -0.046 | 49.1% | 100.0% | 4.00 |
| 旧式point gate | 1.315 | 12.5% | 97.9% | 3.33 |
| CARMA组合效用 + 下置信界 | 0.757 | 2.6% | 61.1% | 1.18 |
| Oracle组合选择 | 2.004 | 0.0% | 97.4% | 3.14 |

这里的`mean gain`是合成损失收益单位，不是F1。CARMA在合成机制中显著降低伤害，但以覆盖率下降为代价，说明评价不能只看平均性能，必须同时报告风险-覆盖率。

## 研究边界

当前准确定位是**多模态对话情感识别中的历史组合效用与风险控制**。本仓库当前不声称：

- 已完成真实多年纵向心理状态建模；
- 具有临床诊断或干预有效性；
- 对任意现实时间漂移提供无条件安全保证；
- 合成实验已经证明真实情感机制成立。

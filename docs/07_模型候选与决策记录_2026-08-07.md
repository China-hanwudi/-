# CARMA-Affect 模型候选与决策记录

## 1. 本轮焦点问题

在不读取当前标签、未来话语或跨切分人物信息的条件下，模型能否学习“某一条历史加入当前历史集合后，会改善还是损害当前情感预测”的条件效用分布，并在伤害风险高时回退到 current-only？

本文件记录的是**研究提案和探索决策**，不是实验发现。现有 EmotionTalk validation 与 MELD dev 已被查看，只能用于问题诊断；新模型选择必须在 train-only 开发区完成。

## 2. 约束与否决条件

- 核心问题必须仍属于情感计算，而不是一般记忆检索。
- 历史只能来自同 dialogue、同 speaker、严格过去。
- 效用监督必须由 group cross-fitting 的 out-of-fold 预测产生。
- 不永久删除历史；所有忽略都是当前查询级、可逆的。
- 任何依赖 test 调参、历史 gold emotion、未来 turn、未授权数据传输或行级结果公开的方案直接否决。
- 本机为 8GB RTX 4070 Laptop，磁盘空间有限；优先冻结编码器、小型 set 模型和流式工件。

## 3. 独立生成的候选方向

### A. SCU-Set：随机子集反事实效用学习

**Idea。** 对每个 train-only OOF 查询随机采样多个历史子集，观测“把候选历史加入当前子集”造成的预测损失变化，训练逐候选、逐集合的效用分布模型；只有校准后的伤害上界小于 0 时才逐步加入候选。

**Assumption。** 冻结 base 在未见 dialogue 上的子集损失差包含可重复的条件效用信号，而不只是 base 噪声。

**Prediction。** 相比 aggregate q90、recent-k 和 similarity top-k，SCU-Set 在相同覆盖率下降低 mean regret、伤害率和尾部 regret，并能在状态恢复后重新选择旧历史。

**Disconfirming evidence。** 候选效用在 cross-fit fold、随机种子或数据集间不稳定；简单 recency/similarity 达到同等结果；或者安全覆盖仍趋近 0。

### B. RCPS-Gate：风险控制选择预测

**Idea。** 不改变 aggregate 历史表示，只把现有 selector 改成 coverage-constrained risk-controlling prediction set，直接优化“在覆盖率至少 c 时，策略 regret 上界是否不大于 0”。

**Assumption。** 当前失败主要来自阈值/校准目标错配，而不是效用不可预测。

**Prediction。** 在固定覆盖约束下，RCPS 比 point/q90 gate 更稳定。

**Disconfirming evidence。** 任意非平凡覆盖下置信上界仍大于 0；或收益只来自更保守拒绝。

### C. Regime-Change Memory：状态突变与恢复模型

**Idea。** 用小型隐状态/change-point 模型估计当前情感状态是否进入新 regime，并让历史权重随 regime 匹配而可逆变化。

**Assumption。** 对话中的历史伤害主要由可识别的状态切换驱动。

**Prediction。** 在状态突变/恢复压力测试中显著优于纯时间衰减。

**Disconfirming evidence。** 短对话无法可靠识别 regime；所谓状态仅复刻当前情感类别或说话人身份。

### D. GPT Memory Critic：GPT 文本教师/基线

**Idea。** 让冻结 GPT 仅查看当前文本和严格过去文本，为每条历史输出“语义冲突、状态延续、暂时不适用”分数，作为 selector 的附加特征或软教师。

**Assumption。** 通用语言模型的语义/语用知识能提供传统 TF-IDF 或小型 embedding 没有的增量。

**Prediction。** 在不读取标签、音视频和未来上下文的条件下，提高伤害 AUC/Spearman，并在蒸馏后保留大部分增益。

**Disconfirming evidence。** 结果对模型快照/提示词不稳定、成本过高、数据传输不合规，或不优于小型多语 embedding。当前无 API key，因此本方向暂不能产生真实结果。

## 4. 预先定义的评估标准

评分为 1–5，分数是决策辅助而非科学证据。

| 标准 | 权重 | 高分含义 |
|---|---:|---|
| 核心问题信息增益 | 0.20 | 能区分“历史本身无用”与“选择/校准失败” |
| 方法原创性潜力 | 0.20 | 不只是 top-k 或阈值替换，能形成独立机制 |
| 统计与泄漏可审计性 | 0.20 | 可 cross-fit、可反证、可做严格对照 |
| 本机可行性 | 0.15 | 8GB GPU 与有限磁盘可完成 |
| 跨数据集迁移 | 0.15 | 可在 MELD/EmotionTalk/IEMOCAP 使用相同合同 |
| 负结果价值 | 0.10 | 即使失败也能形成 benchmark/机制结论 |

## 6. 对抗性审查

### A 的关键反对意见

1. OOF 损失差不是历史的真实因果效应，而是特定 base 的模型依赖效用。
2. 随机子集数量不足会把高阶交互误当成逐条效用。
3. sequential selection 可能积累误差，最后仍退化为全拒绝。

**缓解。** 明确主张为“相对于冻结预测器的条件决策效用”；加入 base 交叉验证、subset 数量敏感性、pair interaction 与 oracle upper bound；用 cluster conformal/RCPS 控制集合级风险。

### B 的关键反对意见

只改风险控制可能是现有选择预测的领域应用，方法创新不足。

**缓解。** 把 B 作为 A 的安全层和强基线，而不是单独主方法。

### C 的关键反对意见

情感标签变化不等于真实心理状态切换，短演员对话不足以识别 latent regime。

**缓解。** 仅作为压力测试/特征消融，不作为主叙事；若无独立证据则删除。

### D 的关键反对意见

闭源快照、提示词调优、隐私和成本会削弱可复现性，而且 GPT 分数可能只是更昂贵的语义相似度。

**缓解。** 预先冻结 prompt/model/temperature，缓存输出，与等信息的小型多语 embedding 比较；无 key 时不运行、不伪造。

## 7. 决策

- **主探索路线：A（SCU-Set）。** 它直接回答逐候选、逐集合的条件边际效用问题，并保留可逆历史。
- **必要安全层与强基线：B（RCPS-Gate）。** 用来判断失败究竟来自效用模型还是风险控制。
- **压力测试：C。** 只有在状态突变与恢复测试显示独立信号时保留。
- **延期基线：D。** 等合法 API key 或明确选择小型开源替代后再运行；不得阻塞非 GPT 主线。

## 8. SCU-Set 最小可行机制

对 train-only OOF 查询 (t) 的候选历史 (h_i) 与随机子集 (S)，构造：

\[
\Delta_{t,i\mid S}
=L\bigl(y_t,F^{-g(t)}(x_t,S\cup\{h_i\})\bigr)
-L\bigl(y_t,F^{-g(t)}(x_t,S)\bigr),
\]

其中 (F^{-g(t)}) 从未在查询所属 group/dialogue 上训练。负值表示加入候选有益。

小型 Set/MLP utility 模型输出 (q_{0.1},q_{0.5},q_{0.9}) 与伤害概率。推理从空历史开始，逐步重算候选的集合条件效用；只有经独立 calibration 修正后的 (q_{0.9}<0) 才加入。未加入的记忆不删除，下一查询可重新使用。

第一阶段只在 train-only exploration partition 上生成监督和诊断；内部 holdout 与公开 test 均保持封存。

### 3.3 样本主键和严格历史

样本主键固定为 `(split, Dialogue_ID, Utterance_ID)`，媒体文件需与 `dia{Dialogue_ID}_utt{Utterance_ID}` 一一对应。

本执行单将最新 `K=3` 具体化为：

- 只在同一 split、同一 dialogue 内查找候选；
- 候选必须满足 `history.Utterance_ID < current.Utterance_ID`；
- 先按 `Utterance_ID` 取严格过去最近 3 条，再按 **oldest→newest** 写入固定槽位：`h_1` 是所选窗口中最早的候选，`h_K` 是离当前最近的候选；不足 K 的 padding 固定放在左侧并由 mask 标记；
- 不限制候选必须与当前说话人相同，并为每个候选保存 `same_speaker`；这样 Phase B 的说话人关系变量不是常量；
- 不足 3 条时用 mask 表达，不复制样本、不补伪历史；
- 没有历史时精确回退 independent current-only；
- 历史候选标签永远不是模型输入。

固定接口：

```text
raw_current x_t^m:        原始 T/A/V 输入引用，m∈{T,A,V}；只供离线 extractor
raw_history x_k^m:        严格过去原始输入引用；只供离线 extractor
qwen_hidden e_i^m:        冻结 Qwen 分模态离线隐状态及 provenance；仓库外 cache
n3_input z_i^m:           P_m(e_i^m)，P_m 为可训练 ModalityProjector；只有 z 进入 N3
current_modalities:       z_t^T/z_t^A/z_t^V
history_modalities:       z_k^m，[B,K=3,modality=3,d_model]
current_modality_mask:    bool [B, 3]
history_mask:             bool [B, 3]
history_modality_mask:    bool [B, 3, 3]
history_sample_ids:       private audit only; [B, 3]
same_speaker:             bool [B, 3]
```

### 3.4 唯一表示链：`raw x → frozen Qwen e → Projector z → N3`

对任意话语 `i` 和模态 `m∈{T,A,V}`，正式表示链固定为：

```text
x_i^m  --冻结的 Qwen3-Omni 分模态离线编码/冻结 pooling-->  e_i^m
e_i^m  --可训练的独立 ModalityProjector P_m-->              z_i^m ∈ R^128
z_i^m  --Phase A 基线或 Phase B N3-->                       emotion logits / N3 output
```

- `x_i^T` 是原始话语文本，`x_i^A` 是对应音频，`x_i^V` 是对应视频/冻结采样帧；不得把手工统计、旧 MM-Align sidecar 或已经融合的张量称为 raw 输入；
- `e_i^T/e_i^A/e_i^V` 必须由冻结的同一 Qwen snapshot **分模态独立调用**得到，分别离线缓存并保存来源哈希、processor、pooling、shape、dtype 和内容哈希；`e` 是 Qwen 产物，不能被训练更新；
- `z_i^m=P_m(e_i^m)` 在训练进程内生成。`P_T/P_A/P_V` 参数互不冒名、随对应 Phase 训练并进入 checkpoint；`z` 是 N3 输入，不能在报告中写成“Qwen 原始 hidden”；
- 原始媒体不可用时，`mask=0`；允许为批处理保存受 mask 保护的零占位，但不得调用 Qwen 后把零占位计为成功的 `e`，也不得让 Projector bias 使缺失模态重新变成可用 `z`；
- N3、情绪/VAD heads、关系、效用和门控都只能消费 `z`、mask 与合规派生量；不得绕过 Projector 直接把 raw `x` 或未经版本绑定的 `e` 混入模型。

```text
p_i/v_i/c_i = mask-aware joint state summaries（如启用）
```

- `p_i` 的监督只来自 train gold emotion；只有存在经协议批准的连续 VAD 标注时才可在 inner-fit/train 内拟合 VAD head。否则只能使用首次训练前已冻结版本、数值、引用和类别顺序的外部 VAD prototype，对预测 posterior 求期望；二者都没有时必须 `B1_BLOCKED_VAD_TARGET_UNDEFINED`，不得临场从离散类别编造、使用全零或伪 target；
- 对任意 train 样本，供后续 `a_k/phi_k` 与 utility 使用的 `p_i/v_i/c_i` 必须来自**没有在该样本所属 dialogue 上拟合**的 group-OOF producer；同一 dialogue 的全部话语只能进入同一 OOF fold；
- producer 包含从冻结 `e` 开始的**全部可学习上游**：状态专用 Projector、模态/联合 emotion/VAD heads 和可学习校准器。每个 inner fold 都必须从 `e` 独立拟合这些参数；不能只 cross-fit 最后一层 head，却让 Projector 或校准器预先看过完整 train 标签；
- 主 N3 Projector 与状态 producer Projector 若分开，必须在 schema/lineage 中区分；若共享设计，OOF sidecar 仍须来自 inner-fit 参数副本，训练行不得改用看过自身 dialogue 的 full-train 副本；
- dev 推理使用只在完整 train 上拟合并冻结的 full-train producer；dev 标签只进入隔离 metric/model-selection evaluator 计算预注册指标，绝不构造 `p/v/c/a/phi/utility` 特征或监督；test gold 只可在 G5 明确授权后进入独立 write-once evaluator；
- Gold 的合法用途只有 train/inner-fit 的 `L_emotion`、状态 producer 监督，以及独立 group-OOF 反事实 evaluator 内计算 utility loss difference target；gold 不得序列化进模型输入，也不得用 dev/test gold 类别查表得到 VAD 后回灌；
- OOF fold assignment、训练行 hash、Projector/head/calibrator config/checkpoint、每行预测来源 fold、prediction hash 和覆盖率写入私有 lineage；OOF 覆盖必须为 100%，不得用 in-sample prediction 填洞；
- `p_i^T/p_i^A/p_i^V`、`v_i^m` 与 `c_i^m` 是跨模态冲突和可靠性建模的来源；每个模态 producer 与 joint producer 都须遵守相同 group-OOF、lineage 和 mask 合同。模态缺失时输出为 unavailable 并由 mask 排除，不得生成伪后验、伪 VAD 或伪置信度。

对当前话语 `t` 与每个候选 `h_k`，先使用 OOF/frozen-producer 输出和非标签元数据确定性构造情感状态/动力学 `a_k`；此时还不能把它命名为 `phi_k`：

```text
a_k = [
  predicted_state(p_t,v_t,c_t,p_k,v_k,c_k),
  vad_delta(v_t,v_k), abs_vad_delta,
  actor_inertia(p_t, p_k, same_speaker_k),
  transition_or_interaction_shift(p_t, p_k, same_speaker_k),
  actor_recovery(v_t, v_k, earlier_same_speaker_history),
  conflict_t(p_t^T,p_t^A,p_t^V,v_t^T,v_t^A,v_t^V,c_t,masks_t),
  conflict_hk(p_k^T,p_k^A,p_k^V,v_k^T,v_k^A,v_k^V,c_k,masks_k),
  optional_conflict_delta,
  delta_time_k,
  same_speaker_k,
  modality_quality_and_availability_k
]
```

- 惯性与恢复是 actor-level 变量，只在 `same_speaker_k=true` 且存在足够严格过去的同说话人 OOF/frozen 轨迹时有效，否则必须 mask；
- 转折冻结为后验/VAD 变化的方向和幅度，不得用 `gold_t != gold_k`；跨说话人候选必须把该变化显式标记为 `interaction_shift`，不得冒充同一 actor 的情绪转折；
- 恢复参考只可来自早于 `t` 的同说话人合法 OOF/frozen 预测；不足时 mask，不能看未来话语或全数据说话人均值补值；
- 跨模态冲突分别计算 `current` 与 `h_k` 两端，并可预注册差值；每一端至少两个模态可用才计算，否则 mask 该端。计算使用后验/VAD方向/置信度分歧及 availability/quality，不能用全零缺失向量制造冲突；
- 时间距离、`same_speaker`、质量和缺失性来自 manifest，不使用标签；
- 所有公式、归一化、阈值、缺失处理和输出维度在看 dev 结果前冻结到版本化配置并计算 SHA。

`a_k` 中的理论分量必须真实进入后续 `phi_k` 并分别可消融：

- VAD；
- 情感惯性；
- 情感转折；
- 恢复；
- 跨模态冲突；
- 时间距离；
- `same_speaker`/说话人关系；
- 模态质量和缺失性。

每个候选的最终计算链固定为：

```text
(z_t, z_k, masks) → R_k^0(逐候选基础3×3)
(R_k^0, a_k, masks) → phi_k = Phi(R_k^0,a_k,masks)
(R_k^0, phi_k, masks) → R_k = Rel(R_k^0,phi_k,masks)
(R_k, phi_k)      → modality-level forward gain / deletion risk
(R_k, phi_k, modality utilities) → joint utility + synergy/conflict residual
g_k^m = G_mod(R_k^m,phi_k,U_k^m,quality_k^m,mask_k^m)
g_k   = G_joint(R_k,phi_k,U_k^joint,U_k^cross,{g_k^m},masks_k)
```

因此 `phi_k` 必须直接进入条件化关系、模态级/联合级效用估计、模态 gate 和候选联合 gate 四条可审计路径；候选 gate 仅通过模态 gate 间接收到 `phi_k` 不合格。只写进 manifest、日志或最终解释但不影响这些计算，不算实现。对每个 `phi` 分量及四条连接分别做干预/置零测试，必须能在合成 fixture 上改变预期的中间量，同时不绕过 mask。

### B1 — fit-only/OOF 双向效用监督 Gate（待实现）

- 先生成并验证上一节从冻结 `e` 开始的 group-OOF `p_i/v_i/c_i`、`a_k`、`R_k^0` 与 `phi_k`；状态 producer 和 utility cross-fitting 可以共享 dialogue fold assignment，但每类预测都必须有独立 lineage；
- 对每个 `h_k` 的 T/A/V 分别估计模态级前向加入收益与后向删除风险；
- 再估计候选联合效用及不可加协同/冲突残差；
- 前向背景 `S` 与后向背景 `R` 必须是预注册的不同集合状态；不得用同一差值换符号伪造双向；
- utility target 只能在 train 内由未见对应 dialogue 的 OOF base/counterfactual evaluator 计算；fit gold 仅在该独立 evaluator 内作为 loss outcome 形成差值，绝不成为 utility head 输入。dev/test gold 不得参与 target 构造；
- 第一级 gate 决定候选内部保留哪些模态；第二级 gate 决定是否保留该候选；
- 无候选通过时精确回退独立 A0：直接返回其 logits/probabilities，不调用 history checkpoint 的空历史路径，不做分数混合；
- OOF 划分按 dialogue 分组；每个 utility target 的全部可学习上游——从冻结 `e` 开始的 Projector、base classifier、状态 producer/校准器与 counterfactual producer——必须来自未在目标 dialogue 上拟合的 inner model；
- receipt 必须分别绑定情绪/VAD head specs、OOF `q/v/phi` manifests、`S`、`R`、fold assignment、base prediction、counterfactual prediction 和 target hashes，并证明 dev/test 标签访问为 0。

B1 只有在 `q/v/phi` 与 utility 的 OOF 覆盖完整、同组不跨 fold、无 in-sample 填洞、`S != R` 且所有 lineage 可复核时 PASS；否则为 `B1_FAIL`。

### B2 — 小样本端到端冒烟 Gate（待实现）

使用确定性选择的 32 train + 8 dev targets，完成 `e→inner-fit state Projector→group-OOF p/v/c→a_k`、`z→R_k^0→phi_k→R_k`、OOF utility loader、两级 gate、forward/backward/optimizer、checkpoint reload、各理论变量及四条 `phi_k` 连接实际影响输出的干预测试，以及 current-only 精确回退。所有 loss/logit/gradient/posterior/VAD/confidence/a/phi/utility 必须 finite；不得用 smoke 指标选择科学设置。失败为 `B2_FAIL`。

### B3 — 五 seeds 全量基线、完整模型与消融 Gate（待实现）

### B4 — 配对统计、冻结与第二停止点（待实现）

# CARMA-Affect研究方案

## 1. 研究状态

- 版本：2026-08-07
- 性质：顶会候选研究方案，尚未经过真实数据主实验验证
- 研究领域：多模态情感计算 / 对话情感识别
- 当前优先级：先完成G0自然负迁移与G1历史交互两个Go/No-Go门

## 2. 核心问题

在不访问当前真实情感标签的条件下，能否判断一组严格过去的同说话人多模态历史整体上会改善还是损害当前情感预测，并在伤害风险不可接受时可靠回退到current-only模型？

旧方案主要问“每一条历史是否有用”；CARMA-Affect进一步问：

> 当多条历史可能互相增强、重复或冲突时，加入某条历史后，整个已选历史组合是否会改善当前预测？如果不能确定，是否应停止选择或回退？

## 3. Task Contract

| 项目 | 冻结定义 |
|---|---|
| 输入 | 当前文本、音频、视频，以及严格早于当前话语的同说话人历史池 |
| 禁止信息 | 当前或历史gold emotion、未来话语、未来派生特征、test label在线更新 |
| 模型输出 | 当前情感分布、所选历史集合、条件边际效用分布、fallback决策 |
| 安全基准 | current-only模型 |
| 主安全目标 | 控制历史策略相对current-only的excess risk和负迁移率 |
| 预算约束 | 最大历史条数或token预算K |
| 统计单位 | query配对；按dialogue / episode / session聚类推断 |

## 4. 核心假设

### H1 自然负迁移

强历史模型会在自然查询子集上稳定劣于current-only，而非仅在人工污染或实现错误条件下受损。

### H2 历史交互

同一候选历史的条件边际效用会随已选集合S变化，部分样本可能出现正负符号反转。

### H3 效用可预测

只使用推理时可见信息，条件效用预测器应超过recency、semantic similarity和query-difficulty基线。

### H4 风险可控制

完整策略的独立校准应在非平凡覆盖率下，降低相对current-only的excess risk和伤害率。

## 5. 预期贡献

1. **组合条件历史效用**：将历史价值从独立逐条评分重新定义为依赖已选集合的条件边际效用。
2. **baseline-relative风险受控选择**：以current-only为安全基准，对完整选择策略进行独立校准和选择性回退。
3. **严格时间安全的实证协议**：系统测量自然负迁移、历史互补/冗余、风险-覆盖率和状态恢复后的历史重用。

上述贡献需要真实数据结果支持。未检索到直接重合工作不等于新颖性已经得到证明。

## 6. Go / No-Go门

| 门 | 通过标准 | 失败处理 |
|---|---|---|
| G0 自然负迁移 | 至少一个强历史基线存在稳定、非人工的伤害子集 | 停止风险控制主张，转为普通ERC或负结果 |
| G1 历史交互 | 条件边际效用随S稳定变化或发生符号反转 | 放弃组合创新，保留point utility |
| G2 可预测性 | 超过recency、similarity和query-difficulty基线 | 停止复杂controller |
| G3 风险控制 | 在预冻结的非平凡覆盖率下降低excess risk | 不得声称安全回退有效 |
| G4 公平预算 | 等token、候选集、参数和训练预算下仍成立 | 结果归因无效 |
| G5 跨数据稳定 | 至少两个数据集方向一致 | 降级为单数据集结论 |
| G6 校准有效 | cluster-level实际风险接近预设阈值 | 不得声称risk guarantee |

## 7. 分阶段执行计划

| 阶段 | 工作 | 输出 |
|---|---|---|
| P0 问题确认 | MELD train/dev复现强基线并测量自然负迁移 | G0报告与误差图谱 |
| P1 交互确认 | 在EmotionTalk/IEMOCAP train内采样历史组合 | 符号反转与交互统计 |
| P2 方法MVP | 实现分布式效用预测器与组合选择器 | CARMA-Lite、消融、计算审计 |
| P3 风险校准 | 冻结候选策略并做cluster-level独立校准 | 风险-覆盖率曲线 |
| P4 主确认 | 跨数据、跨语言、状态转折和模态缺失 | 主结果、机制与边界 |
| P5 投稿准备 | 模拟审稿、复现、代码和数据卡 | 论文、附录、复现包 |

## 8. 不可越界表述

当前不能声称：首次发现历史并非总有用、首次提出查询条件化记忆有效性、首次让模型决定何时遗忘、对任意时间漂移提供绝对安全保证，或合成实验已经证明真实情感机制成立。

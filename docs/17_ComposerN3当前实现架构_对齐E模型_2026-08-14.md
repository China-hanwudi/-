# TemporalN3 UnifiedTemporalFinal：源码级架构说明

> 更新：2026-09-13。本文以同步后的 `模型/n3_affect/` 源码为准，目标数据集为 M3ED 与 CMU-MOSEI。旧版 ComposerN3/MELD 说明只作为历史记录，不代表当前主线。

## 1. 一句话

当前模型将六路 T/A/V 编码、当前-only 锚点、三模态 3×3 关系证据、双向效用、两级门控、说话人条件历史状态和候选级动态证据路由组合起来；当历史候选风险超过阈值时，`CandidateRiskFallback` 回退到当前-only 预测。

## 2. 真实数据流

```text
当前 turn: Tₜ / Aₜ / Vₜ       严格过去历史: Tₕ / Aₕ / Vₕ
          │                                  │
          ├─ SixWayEncoders                  ├─ history_mask
          ├─ current_fuse                    ├─ speaker_state_net + GRUCell
          ├─ Transformer current anchor      ├─ HistoricalEvidenceController
          │                                  └─ history_fuse / temporal deltas
          └───────────────┬──────────────────────────┘
                          ▼
          SharedThreeByThree: alignment / complementarity / conflict
                          ▼
          BidirectionalUtilityHeads + TwoLevelGate
                          ▼
          DynamicEvidenceRouter
          ├─ candidate-level T/A/V weights
          ├─ modality uncertainty and disagreement
          └─ candidate logits
                          ▼
          conflict_v2 features: entropy / confidence margin / label flip / JS
                          ▼
          CandidateRiskFallback → hard-safe / soft-gate / current-only
                          ▼
          classification logits + probabilities + VAD auxiliary output
```

## 3. 模块对应关系

| 模块 | 源码 | 作用 |
|---|---|---|
| 配置 | `config.py` | text=2048、audio=1536、video=768、`d_model=128`、类别和风险版本 |
| 六路编码 | `encoders.py:SixWayEncoders` | 当前/历史 T/A/V 投影，支持千问文本塔和侧车音视频特征 |
| 当前锚点 | `model.py:_current_logits` | 当前三模态 token 经 Transformer 得到 current-only logits |
| 关系证据 | `relation.py:SharedThreeByThree` | 当前模态 × 历史模态的 3×3 关系网格 |
| 效用/门控 | `utility.py:BidirectionalUtilityHeads`、`gating.py:TwoLevelGate` | 估计加入历史和模态的收益、风险与混合权重 |
| 历史控制 | `model.py:HistoricalEvidenceController` | query/key/value 检索、边界分数和有界 recency decay |
| 说话人状态 | `model.py:speaker_state_net/speaker_state_cell` | 逆序历史槽位按时间更新 same-speaker 条件 GRU 状态 |
| 动态路由 | `multimodal_router.py:DynamicEvidenceRouter` | 每个候选单独生成 T/A/V 证据权重、质量、不确定性和候选 logits |
| 风险回退 | `hard_fallback.py:CandidateRiskFallback` | 使用关系、冲突和不确定性特征过滤候选；失败时返回 current-only |
| 分类头 | `model.py:classifier` | 输出数据集对应的情感 logits |
| 辅助头 | `model.py:TheoryAuxHead` | 输出 3 维 VAD 辅助信号 |
| 回归适配 | `regression_model.py`、`regression_router.py` | CMU-MOSEI 连续情感回归路径 |

## 4. 当前数据协议

M3ED 与 CMU-MOSEI 必须分别维护 train、validation 和 test manifest。历史只能来自严格过去的 turn；test 不参与 checkpoint、阈值、路由校准或特征选择。每个 manifest 要记录标签协议、模态可用性、特征维度、数据清单哈希和 split 哈希。

当前默认特征维度：文本 2048、音频 1536、视频 768；统一表示维度 128。千问权重不进入 GitHub，模型只保留其路径配置和文本特征接口。

## 5. 状态边界

当前 manifest 的 compile、合成前向/反向和回归实际维度 smoke test 已通过；M3ED 与 CMU-MOSEI 正式训练尚未开始。本仓库不把源码 smoke test 写成数据集性能结果，也不包含 checkpoint、原始数据或预计算特征。

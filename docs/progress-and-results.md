## 3. MELD真实音频＋文本Pilot

### 3.1 实验边界

- 数据：MELD官方train/dev CSV和真实WAV；train 9,988条、dev 1,108条可对齐样本。
- 评估：765个具有同说话人严格过去历史的dev查询，来自103个dialogue。
- 模态：官方文本＋35维无标签轻量声学统计，不含视觉；不是完整三模态实验。
- 防泄漏：同dialogue、同speaker、严格过去；train内按dialogue做5折cross-fitting；selector-fit与calibration按dialogue隔离。
- 统计：5个随机种子ensemble；2,000次dialogue聚类bootstrap；MELD test未打开。

### 3.2 主要结果

| 项目 | 结果 |
|---|---:|
| Current-only Accuracy / Weighted-F1 / Macro-F1 | 0.4783 / 0.4336 / 0.2949 |
| Full-history Accuracy / Weighted-F1 / Macro-F1 | 0.4720 / 0.4234 / 0.2776 |
| 自然历史伤害率 | 43.27%（95% CI 39.39%–47.23%） |
| 平均超额NLL | +0.084（95% CI -0.061–+0.227） |
| 受损查询平均伤害 | 1.078 nats（95% CI 0.891–1.259） |
| 超额NLL p90 / p99 | 1.623 / 4.555 |
| 文本meta harm AUC | 0.6065 |
| 文本＋轻量声学 harm AUC | 0.5954 |
| 音频AUC增量 | -0.0111（95% CI -0.0457–+0.0230） |
| 严格conformal q90历史覆盖率 | 0% |

### 3.3 决策

- **问题存在性：初步PASS。** 自然历史在大量查询上造成伤害，且尾部风险明显。
- **轻量音频增量：FAIL。** 当前35维声学表征没有提高伤害预测。
- **非平凡安全回退：FAIL。** 严格q90策略全拒绝历史，不能算方法成功。
- **CARMA组合创新：尚未验证。** 本Pilot验证的是point-risk基线和问题存在性，不是组合条件边际效用模型的主实验。

## 4. 合成sanity check

### 4.1 环境说明

合成生成器预先写入：

- 稳定阶段和状态突变；
- 语义相似但状态失配的历史；
- 历史之间的负冗余；
- 带噪声的可观察匹配特征。

每次最多选择4条历史，共运行12个随机种子。`mean gain`是合成损失收益单位，不是F1。

### 4.2 结果

| 虚拟策略 | 平均收益 | 伤害比例 | 使用覆盖率 | 平均历史数 |
|---|---:|---:|---:|---:|
| 全部8条历史 | -2.141 | 71.8% | 100.0% | 8.00 |
| Recent-4 | -0.046 | 49.1% | 100.0% | 4.00 |
| 旧式point gate | 1.315 | 12.5% | 97.9% | 3.33 |
| CARMA组合效用 + 下置信界 | 0.757 | 2.6% | 61.1% | 1.18 |
| Oracle组合选择 | 2.004 | 0.0% | 97.4% | 3.14 |

### 4.3 正确解读

- 全部历史和Recent-4在预设机制中产生明显负迁移。
- point gate获得更高平均收益，但保留约12.5%的有害选择。
- CARMA将伤害比例降到约2.6%，代价是覆盖率降到约61.1%。
- 这说明风险方法必须同时报告性能、伤害和覆盖率。
- 这些结果不能证明真实数据存在自然负迁移、历史交互或相同风险结构。

## 6. 最近里程碑

### P0：自然负迁移确认

1. 在MELD train/dev复现current-only与强历史基线。
2. 统一token、候选池、参数和计算预算。
3. 输出query级伤害图谱、尾部伤害和cluster bootstrap CI。
4. 若G0失败，停止完整风险控制主张。

### P1：历史交互确认

1. 在EmotionTalk或IEMOCAP train内采样`(S,h_i)`组合。
2. 估计条件边际效用随S的变化。
3. 报告条件方差、符号反转率和互补/冗余案例。
4. 若G1失败，退回简单point utility方案。

### P2-P3：方法与校准

仅在G0/G1通过后：

1. 实现条件效用分布预测器与逐步选择器。
2. 完成去组合条件、去不确定性、去策略校准和去fallback消融。
3. 在独立calibration split上冻结候选策略阈值。
4. 输出harm/excess-risk/F1-coverage曲线。

## 7. 风险与缓解

| 风险 | 影响 | 缓解策略 |
|---|---|---|
| 自然负迁移很弱 | 风险控制问题不成立 | 先执行G0，失败即停止复杂模型 |
| 历史交互很弱 | 组合创新退化为point gate | 先执行G1并报告符号反转 |
| 历史池浅 | 难以检验组合机制 | MELD做Pilot，EmotionTalk/IEMOCAP做主确认 |
| 聚类独立单位少 | 校准不稳定 | cluster-level校准、宽CI、跨数据重复 |
| 风险下降仅来自大量拒绝 | 实用性不足 | 预冻结非平凡覆盖率，完整报告权衡 |
| 方法被已有工作覆盖 | 新颖性不足 | closest-work全文审计与强基线公平比较 |

# 核心问题与研究定位

> **历史定位说明（2026-08-13）：**本文记录 2026-08-07 前后围绕 N2/历史负迁移诊断形成的问题定位与已观察探索证据，供追溯使用；其中“方法型论文路线暂时停止”等判断已被最新 N3 两阶段方案替代，不再作为当前执行结论。当前执行以 [最新执行基线](14_最新执行基线与GitHub旧方案差异_2026-08-13.md) 为准：Phase A 建立冻结 Qwen 三模态 emotion-only 基线，Phase B 才检验逐 `h_k` 3×3、情感理论、真实双向效用与两级门控。本文数字不得冒充新管线或完整 N3 结果。

## 1. 研究方向没有改变，但问题已经收窄

大方向仍是情感计算中的纵向个性化：利用一个人的过去观测帮助预测当前情感。研究不再把“历史并非总有用”“查询条件化地选择记忆”或“动态检索/遗忘”本身声称为首次创新，因为 MemConflict（arXiv:2605.20926）和 MemCon（arXiv:2607.13591）已经覆盖了相邻的一般记忆问题。

当前核心问题是：

> 在不访问当前真实情感标签的条件下，能否用严格时间安全的预测证据，预测加入同说话人历史后会改善还是损害当前情感预测，并在损害风险较高时可靠回退到 current-only？

研究对象不是永久删除记忆，而是查询级、可逆地决定本次是否使用历史。

## 2. 可计算目标

对查询 \(t\) 定义：

\[
\Delta L_t = L(y_t, \hat y_t^{\text{full-history}})
- L(y_t, \hat y_t^{\text{current-only}}).
\]

- \(\Delta L_t>0\)：加入历史使当前预测更差，即发生负迁移；
- \(\Delta L_t<0\)：加入历史使当前预测更好；
- 训练风险模型时可以使用 train 内 cross-fit 得到的 \(\Delta L_t\)；
- validation/test 推理时不能访问 \(y_t\)，只能预测风险。

## 3. 三个可证伪问题

### Q1：自然负迁移是否真实存在？

在不人工污染历史的真实对话数据中，无条件使用同说话人历史是否会稳定伤害一部分查询？

当前答案：**是。** MELD 与 EmotionTalk 均观察到大量查询的 NLL 上升，而且伤害具有明显尾部。

### Q2：历史伤害能否由测试时可见信号预测？

文本、音频、视频中的当前—历史关系、模型置信度变化和模态质量信息，能否预测 \(\Delta L_t\)？

当前答案：**部分可以。** EmotionTalk 三模态 selector 明显超过文本 selector，但绝对 AUC 仍只有 0.6773。

### Q3：这种可预测性是否足以支持安全且非平凡的历史使用？

风险上界小于零时放行历史，能否同时取得至少 10% 覆盖，并证明相对 current-only 的平均 regret 不大于零？

当前答案：**不能。** 严格 q90 仅覆盖 0.51%，且均值 regret 的置信区间上界仍为正。

## 4. 当前最可信的贡献定位

目前可以继续论证：

1. 一个跨数据集、逐查询的历史负迁移现象；
2. 平均 F1/accuracy 改善可能掩盖概率风险与受损个体；
3. 时间安全的 current-only/full-history 配对反事实、尾部 regret、风险—覆盖和聚类 bootstrap 协议；
4. 多模态信号能提高伤害可预测性，但尚不足以实现安全部署。

目前不能声称：

- 当前 CARMA 已经成功解决安全历史使用；
- 首次提出查询条件化记忆有效性或动态记忆控制；
- 结果证明真实长期心理状态、临床有效性或可穿戴部署；
- validation 上的阈值可以继续调整后仍作为确认性结果。

## 5. 当前论文路线

方法型论文路线暂时停止。更可行的路线是构建“情感模型历史负迁移 benchmark／诊断论文”：系统回答哪些查询被历史伤害、平均指标为何掩盖伤害、常见控制器为何难以在非平凡覆盖下提供安全保证。

# 方法与实验协议

## 1. 记号与定义

- `x_t`：当前多模态话语。
- `H_<t`：严格早于当前话语的同说话人历史池。
- `S`：当前已选历史子集。
- `h_i`：尚未加入S的候选历史。
- `f_0(x_t)`：current-only预测器。
- `f(x_t,S)`：使用当前信息和历史子集S的预测器。

历史组合相对current-only的整体效用定义为：

```text
G_t(S) = loss(f_0(x_t), y_t) - loss(f(x_t, S), y_t)
```

- `G_t(S) > 0`：该历史组合改善当前预测。
- `G_t(S) < 0`：该历史组合造成负迁移。

候选历史在已选集合条件下的边际效用为：

```text
M_{t,i|S} = loss(f(x_t,S), y_t)
            - loss(f(x_t,S union {h_i}), y_t)
```

该定义允许同一历史随着S变化而表现为互补、冗余或冲突。

## 2. 训练期折外效用生成

1. 只在train内部按dialogue / episode / session进行嵌套cross-fitting。
2. 每个查询优先采样4-8个`(S, h_i)`组合，其中`h_i`不属于S；不枚举全部`2^n`集合。
3. 使用未见过该查询所属fold的预测器产生`f_0`、`f_S`和`f_{S union {h_i}}`。
4. 用折外预测损失差生成`M_{t,i|S}`标签。
5. 该标签只监督条件效用模型；dev/test不生成gold utility。

当前方案没有预先规定情感模型与效用模型必须采用联合损失端到端优化。

## 3. 条件效用分布预测器

控制器使用以下推理时可见信息：

- 当前查询表征；
- 候选历史表征；
- 已选集合摘要；
- 时间间隔和对话结构；
- 模态可靠度。

输出包括条件分位数或伤害概率，例如：

```text
Q_theta(tau | x_t, h_i, S)
P_theta(M_{t,i|S} < 0)
```

目标不仅是估计平均效用，还要评估最坏合理情况下是否可能有害。

## 4. 测试期历史组合选择

1. 从空集合开始。
2. 在预算K内，为所有剩余候选预测条件边际效用分布。
3. 选择安全边际最高的候选。
4. 只有下置信界`LCB > 0`时才加入。
5. 每加入一条历史后重新评估其余候选。
6. 所有候选均不安全时停止；空集合对应current-only回退。

这里的风险约束不是对每个测试样本的无条件保证。测试使用的是独立校准后冻结的完整策略阈值。

## 5. 策略级独立校准

单条候选的置信区间不能自动保证多步自适应选择后的整个集合安全。因此需要：

1. 在独立calibration split上冻结一组候选策略阈值；
2. 按dialogue / episode / session聚类单位检验完整策略相对current-only的excess risk；
3. 选择满足风险约束的最激进策略；
4. 在测试前冻结模型、风险水平、阈值、覆盖率要求和分析代码。

有限样本风险保证依赖明确的独立/交换性或聚类交换性假设。现实时间漂移需要滚动校准和外部stress test单独评价。

## 6. 数据集角色

| 数据集 | 研究角色 | 匹配度 | 主要限制 |
|---|---|---|---|
| MELD | 快速Pilot、自然负迁移与泄漏审计 | 基础假设 | train中约17.4%查询有不少于5条历史；episode跨切分风险需审计 |
| EmotionTalk | 组合效用主实验、中文/跨语言验证 | 最高 | train约62.6%查询有不少于5条历史；原始媒体与许可仍需确认 |
| IEMOCAP | 深历史、状态转折与恢复验证 | 较高 | 需申请；仅10位演员，session级独立单元有限 |
| CPED / M3ED | 备用与扩展 | 条件匹配 | 版权、特征来源、turn重构和时间泄漏需审计 |

## 7. 强制基线

- Current-only多模态模型；
- Full-history及标准对话上下文模型；
- Recent-k、Time Decay、Semantic RAG top-k；
- 独立逐历史point utility gate；
- 普通分类置信度回退与SelectiveNet-style rejector；
- MemCon-style自适应记忆控制器；
- CARMA去掉组合条件、不确定性、策略级校准或fallback的消融；
- Oracle集合选择，仅作为分析上界。

所有比较需要控制token、候选集、参数量和训练/计算预算。

## 8. 决定性实验

| 实验 | 回答的问题 | 关键指标/诊断 |
|---|---|---|
| E1 自然负迁移 | 真实历史是否可能伤害当前预测 | harm rate、excess loss、尾部伤害、cluster bootstrap CI |
| E2 历史交互 | 条件边际效用是否显著依赖S | 条件方差、符号反转率、冗余/互补案例 |
| E3 历史特异性 | 控制器是否只在预测查询难度 | 固定query换history、固定history换query、身份置换 |
| E4 风险-覆盖率 | 是否在非平凡覆盖率下降低伤害 | harm-coverage、excess-risk-coverage、F1-coverage |
| E5 状态转折与恢复 | 暂时忽略后能否重用旧历史 | 使用->忽略->恢复轨迹、同一历史权重反转 |
| E6 分布变化 | 校准能否跨说话人、语言和模态缺失保持 | speaker/episode隔离、跨数据集、缺失模态stress test |

## 9. 指标与统计协议

- 数据集公认主指标；
- macro/weighted F1；
- NLL、Brier、ECE；
- harm rate、excess loss和尾部伤害；
- 风险-覆盖率曲线；
- 至少5个训练随机种子，不报告最佳种子；
- query级配对比较，按dialogue / episode / session聚类bootstrap；
- 同时报告均值、置信区间、个体/说话人分层结果和最坏组伤害；
- 测试集只在全部决策冻结后运行一次。

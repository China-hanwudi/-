## 当前路线判定

### 可以继续

- 历史负迁移 benchmark；
- 平均性能与逐查询安全之间的差异；
- 重尾 regret、风险—覆盖、配对历史置换和时间泄漏审计；
- “多模态能提高伤害预测，但仍不足以安全使用历史”的有条件机制结论。

- 把现有 selector 包装为成功的 CARMA 方法；
- 在已经使用过的 validation 上继续换阈值并当作确认性结果；
- 在未获得授权前声称完成 IEMOCAP；
- 把演员对话结果外推到临床、自然长期生活或可穿戴部署。

## 下一步优先级

1. **完成无损 train-only OOF base cache。** 必须覆盖五折/五seed，并记录组、配置和散列；旧 float32 cache 与可见 hurdle 结果继续隔离。
2. **生成非平凡不同集合监督。** 对 history≥2 的查询生成 `S` 和 `T`，产生 `P(S)`、`P(S+h_i)`、`P(T)`、`P(T-h_i)`。
3. **运行三组主反证。** 双向 vs forward-only/backward-only；情感约束 vs 无情感约束；3×3 vs 简单拼接。
4. **只在 train-only GO 后做 calibration。** 未通过时停止复杂化，保留 benchmark/负结果路线。
5. **并行申请 IEMOCAP。** 许可获批前只准备代码合同；获批后冻结 session-wise 切分和类别映射。
6. **最后才启封 test。** 论文问题、主要指标、模型、阈值和统计门共同冻结后，执行一次独立终验。

## 方法路线重新GO的最低条件

至少需要在新的确认数据上同时满足：

- 风险预测相对简单文本/recency/similarity基线有稳定增量；
- 严格策略覆盖率达到预注册的非平凡下限；
- 相对current-only的平均regret及其聚类置信区间上界不大于0；
- 被放行历史的伤害率显著低于always-history；
- 结论跨随机种子和至少两个独立数据源稳定。

在这些条件满足前，最诚实的项目状态是：**实验工程PASS，问题价值PASS，当前方法FAIL，benchmark路线GO。**

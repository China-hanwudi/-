## 三、如实记录

1. clip 是唯一在所有参照系都为正的分支；uncond（视觉但无底座条件）也高于
   scene（+0.30 pt），说明证据本身有信号，**条件机制在其上再加 +0.40 pt**。
2. clip_shuffled（0.6431）略低于 scene（0.6451）：打乱对应后残余微弱负效应——
   与"增益来自真实对应"一致，不留"打乱仍增益"的反例。
3. 两 seed 时期的 CE 变差现象在 5 seed 上待逐 seed 核对（见各 run history）；
   WF1 增益不等于概率质量增益，论文中分开报告。
4. 5 个 scene 参考中 3 个（43/71/101）为本次按 Codex 同 hash 训练器同配方补训
   （hash 23f9104c…一致），2 个复用 Codex pilot——配对关系成立。
5. 工程：驱动 bug 2 次（丢 run 竞态、reload 类未按 mode 实例化）修复留痕；
   21 fit 总 GPU 约 0.43 GPUh（1538s+180s）。

## 四、C 项：人脸身份抽查（代理级，非人工委员会）

- 材料：`model7/audit/face_audit_valid_kimi.png`（valid 30 例，绿框=选中目标，
  红框=其他人脸；含 id/speaker/匹配分/差距）。
- 我的判读（ReadMediaFile，降采样图）：可判 22/30 中——约 12 例选中合理、
  约 7 例拒选正确（背影/片尾字幕/远景无人脸）；**疑似错选 2–3 例**
  （Rachel 样本疑似选中 Monica 长相者 ×2、Joey 样本疑似选中 Chandler 长相者 ×1）；
  **疑似漏选 1 例**（明显 Rachel 脸被低分拒选）；8/30 因分辨率/角度无法判断。
- 结论：自动原型匹配**粗可用但有可观测错选/漏选**（我的疑似率 ~10%），
  不能声称"说话人定位已验收"。**需要用户/组员按图复核**（清单在审计目录）；
  复核前，论文只写"原型匹配的目标人脸"，不写"正确说话人"。
- YuNet/SFace 权重许可证：assets 目录各有 LICENSE 文件（在案）。

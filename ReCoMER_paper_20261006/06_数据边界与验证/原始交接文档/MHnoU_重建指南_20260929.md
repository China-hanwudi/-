## 第二部分：结构图导读 + 创新点在图上的位置

图：`MHnoU（model6）结构图 · 自控框图风格`（工作区 `MHnoU_structure.png`）。部署配置 use_history K=3 · utility=shapley · deploy=solo_weighted · d=192 · W9 全关。

### 图上每个编号的身份

| 图上的块 | 源码位置（n6/model.py） | 输入 → 输出 | 公式 |
|---|---|---|---|
| 当前话语特征 | data.py 打包 | T/A/V 池化向量 | — |
| ① 模态编码器 | `ModalityEncoder` ×3（历史复用同权重） | x_m → e_m（192 维） | LN→Linear→+模态嵌入→GELU→Dropout→LN |
| 求和点 ⊕（红圈 ×3） | `HistoryAttnPool.forward` 内 | e_m + γ·p_m → e′_m | e′ = e + γ·p，γ 零初始化 |
| ② solo 头 ×3 | `solo_heads` | e′_m → z_m（7 维 logits） | z_m = W_m·e′ + b_m |
| 加权求和 ⊕Σ | `forward` 末段 deploy | Σ w_m·z_m → 输出 | w = softmax(μ/τ)，下限 ε=0.05 再归一 |
| ③ 效用电头 g_φ | `UtilityHead` | 582 维特征 → μ（3 维效用） | μ = W_mu·φ(W_u·u) |
| ④ 历史证据汇聚 | `HistoryAttnPool` | 以 e_m 为查询，注意力池有效历史槽 | α = softmax((h·q)/√d)，掩码，p = Σ α_j·h_j |
| γ 增益 | `HistoryAttnPool.gamma` | LayerScale 零初始化 | 开局恒等；全掩码严格归零 |
| 历史槽位输入 | data.py `_history` | 前 3 句 ×3 模态 + 三层掩码 | 有效性 × 模态 × 同说话人 |
| 仅训练虚线框 | `measure_shapley` | 联合头遍历 7 子集 → 实测 φ | φ_m = Σ_S w_S·[U(S∪m)−U(S)]，逐样本标准化 |

### 创新点 1（闭环）在图上的位置

- **位置**：就是"④ 历史证据汇聚 → γ 增益 → 求和点 ⊕ → ② solo 头 → ③ g_φ → 加权求和"这整条**蓝色反馈通道 + 门控支路**的**连接顺序**。
- **替代了什么**：替代了两种旧接法——历史不在末端拼接（那是把蓝色线从 ⊕ 挪到输出前），判断不发生在反馈之前（那是把 ③ 挪到 ⊕ 前面）。
- **怎么运作**：历史证据先经 ⊕ 注入 e′，②③ 全部在 e′ 上重新计算——历史改变了后续所有判断所依据的状态。
- **实现什么功能**：历史证据必须经过"再判断"才能影响输出；无历史时严格退化为纯当前判断（掩码归零保证）。
- **为什么**：末端拼接让垃圾历史直通决策；先行注入让"谁可靠"的评估停留在旧状态。闭环 = 用当前状态选证据 → 证据改变状态 → 在新状态上重新评估。

### 创新点 2（Shapley 门控）在图上的位置

- **位置**：**③ 效用电头 g_φ 的"教材"**——图左下角虚线框（联合头遍历 7 子集 → 实测 Shapley φ）就是它的专属部件；g_φ 本体是通用门控网络。
- **替代了什么**：替代了 DF-ERC 式教师信号——别人的门控学"置信度（TCP）"，我们的门控学"实测边际贡献（φ̂）"，**门控架子本身不换**。
- **怎么运作**：训练时每步用模型自己的联合头对 7 个模态子集做反事实评估得 U(S)，按 Shapley 公式算逐样本贡献 φ，标准化后当 g_φ 的回归目标；推理时 g_φ 预测贡献定权重（教师退场，零额外成本）。
- **实现什么功能**：权重由"真实贡献"决定，"自信但错"的模态（文本霸屏）骗不了它。
- **为什么**：置信度是代理信号、会骗人；边际贡献是公理化测度量（1953 年 Shapley 值，对称/有效/可加）。
- **实验备注**：教师信号 +0.5 pt 显著；但**门控架子 −1 pt 有害**——重建时默认 utility=uniform，Shapley 教师待嫁接到新载体。
- **配套公式 4（中心化有界权重）的位置**：**"w = softmax(μ/τ)"那个方块的内部**——把贡献值变成权重的最后一步；总量守恒、偏移封顶（出处锚：统计学收缩估计 / 优化信赖域）。默认未启用（在 deploy_weights 内替换 softmax 即接入）。

### 创新点 3（弃权机制）在图上的位置

- **位置**：**④ 历史证据汇聚的"候选名单"**——注意力打分之前，键序列从 [K 个历史槽] 变成 [K 个历史槽 + 1 个空候选]；softmax 归一化后空候选的质量 = 弃权概率。
- **替代了什么**：不改 softmax 公式，只改它的输入——传统 softmax 权重和恒为 1 给不出精确的"零"，加空候选后"整碗端走"在数学上合法。
- **怎么运作**：空候选是零初始化可学习向量（null_emb）；训练时用"历史槽情绪是否与当前句一致"（label[history_index] 可得）当 BCE 监督：一致则压空候选、全不一致则推空候选；推理时模型逐句自决。γ 零初始化保证开局恒等。
- **实现什么功能**：自足话语（"我中奖了！"）自动免听历史，降噪；拒绝时机数据驱动、换数据集免调参；白送"弃权率"分析指标。
- **为什么**：softmax 数学上给不出零，注意力只能"少听"不能"不听"；空候选给了精确的零。

## 第四部分：关键实现规格（照抄即可）

**配置默认值**：d_model=192，dropout=0.15，K=3，batch=64，lr=1e-4，warmup 2 + cosine 10，SWA 窗口 3，patience 6，eps_floor=0.05，τ=1.0，λ_u=0.3（仅 shapley），λ_c=0.05（KL 一致性），label_smoothing=0.05，类别权重 cap=2，mask_fusion_fix 默认开。

**选点规则**：valid WF1 > Macro-F1 > Acc > −CE；SWA(3) 候选（窗口不满不得当选）；含 epoch −1 回退（基线恒等初始化）。

**历史掩码**：有效性 × 模态归属 × 同说话人（speaker_same）；全掩码时注意力权重全零 → p=0 → e′=e 严格成立（即"零历史差分"性质，无需额外代码）。

**Shapley 实测**（仅 --utility shapley 时）：每训练步 no_grad 用联合头对当前 token 的 7 个非空模态子集算 U(S)=log_softmax(z_S)[y]，φ 按 |S|!(2−|S|)!/3! 加权，逐样本标准化（mean 0/std 1）后监督 μ；MSE 权重 λ_u。

**弃权补丁**（附录 B 全文在本地 `abstain_setup.py`，含 model/data/train 三处补丁的完整新旧代码）：null_emb 零初始化；BCE 监督 λ=0.1；`--abstain` / `--abstain-lambda` 开关。

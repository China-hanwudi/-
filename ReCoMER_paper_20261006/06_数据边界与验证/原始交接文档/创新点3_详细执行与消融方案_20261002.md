## 五 阶段二 实现历史摘要与句级开关

### 1 历史摘要

对每个模态 `m`：

```text
e_m = encoder_m(current_m)                       [B,D]
h_m = encoder_m(history_m)                       [B,K,D]
mask_m = history_mask * history_modality_mask_m   [B,K]
alpha_m = masked_attention(e_m, h_m, mask_m)      [B,K]
p_m = sum(alpha_m * h_m)                         [B,D]
```

保持既有 q_proj 和 gamma，不新增历史编码器。全mask时 `alpha_m=0`、`p_m=0`，不能输出NaN。K=0单独处理。padding槽不得参与分母、相似度最大值或情绪摘要。

计算顺序固定：编码当前句和历史，构造尚未反馈的特征，输出保留概率，应用反馈，再计算原有预测。不得用已经融合历史的当前表示反过来生成这一轮开关特征。

### 2 固定24维输入特征

第一版用固定顺序的24维统计特征，不直接拼接高维表示，避免小模块变成新的大型融合器。

| 位置 | 特征 | 维度与计算 |
| --- | --- | --- |
| 0至8 | 当前句T/A/V的归一化预测熵、top1-top2概率差、当前模态是否存在 | 每模态3维，共9维 |
| 9至11 | 每模态有效历史槽比例 | sum(mask_m)/K，共3维；K=0为0 |
| 12至14 | 当前预测分布与历史摘要预测分布的JS差异 | 每模态1维，共3维，除以log(2)归一化 |
| 15至17 | 历史摘要预测分布的归一化熵 | 每模态1维，共3维 |
| 18 | 有效历史中同说话人比例 | 无说话人元数据为0 |
| 19 | 说话人元数据是否可用 | 0或1 |
| 20 | 任一模态可用的历史槽比例 | 不把三模态均缺失的槽计入 |
| 21至23 | 原始文本特征与有效文本历史的余弦相似度均值、最大值、按文本alpha加权均值 | 共3维；无可用文本历史为0 |

预测分布来自 `softmax(solo_head_m(e_m))` 与 `softmax(solo_head_m(p_m))`；这是辅助表征，不保证历史摘要分类头已经校准。两个分布均不得读取真实情绪标签。JS只在当前模态与该模态历史均可用时计算，否则设为0；历史熵在无该模态历史时设为0。熵以log(C)归一化。

文本相似度使用包中的同一来源原始T向量。余弦先截断到[-1,1]，可映射到[0,1]。零范数向量视为无可用相似度，不产生NaN。

`base` 消融仍保留24维网络，但将位置21至23置零。`semantic` 使用全部特征，保证参数量相同。`base` 已含预测情绪差异；这项消融仅检验额外文本语义信息。

全部统计特征传入开关前 `.detach()`。任务梯度仍通过反馈残差作用于开关和主干；辅助BCE不通过特征反向迫使主干制造“好判断”的输入。特征分离不能切断开关网络本身的梯度。

### 3 小网络和空历史

```text
keep_logit = Linear(24,32) -> GELU -> Linear(32,1)
s = sigmoid(keep_logit)                           [B]
```

参数量833。第一版不加dropout、BatchNorm或额外编码器。初始最后一层bias设为logit(0.8)，权重可小幅初始化；这是“开局倾向保留”的工程选择，不是实验结论。

若样本无任何可用历史：强制执行门为0，不计算该样本的开关BCE，也不计入有历史样本的拒绝率分母。概率输出可设为0，并标注 `has_history=False`。

## 六 阶段三 实现硬执行与完整断路

### 1 训练日程

用从0开始的epoch编号：

- epoch 0至2：实际反馈保留门为1，仅训练开关判别；BCE系数依次0.1、0.2、0.3。
- epoch 3至4：使用连续s控制残差，BCE系数0.3。
- epoch 5开始：hard臂用二值门，soft臂继续用连续s；BCE系数0.3。
- 主实验epoch 5以后固定温度1.0和阈值0.5。第一版不额外扫描温度、阈值、隐藏宽度和lambda。

无历史样本始终门为0。warmup最初3轮的checkpoint不参与最佳模型选择；开发集loss早停计数在正式执行日程开始后重新初始化，避免仅因切换开关造成自动提前终止。soft和hard臂都从epoch 5起选择checkpoint，保证候选预算可比。

hard残差门的训练代码语义为：

```python
hard = (keep_prob >= threshold).to(keep_prob.dtype)
gate_st = hard + keep_prob - keep_prob.detach()
e_final = e_base + gate_st.unsqueeze(-1) * gamma * pooled_history
```

eval时直接用hard，不使用直通估计。不允许仅用sigmoid后称为硬拒绝。

### 2 历史路径处理

- SOLO预测的当前表示：统一乘同一句级门。
- joint head的历史token：hard拒绝行必须把对应padding mask置为不可见，并从masked mean的分母中排除。保留行不额外乘s，避免重复衰减。
- soft臂：历史残差乘s，raw history token乘s；s精确等于0或强制关闭时仍须mask排除。这是“软执行近似”的对照，不等价于按s概率随机删除整个历史。不得把比较解释成只检验一个残差乘法。
- joint的当前token使用同一门处理后的当前表示。
- 不能简单把 `token_mask *= s` 当作attention屏蔽，因为现有key_padding_mask只检查是否大于0；且分母归一化可能抵消缩放。
- 主实验禁用mpath等可选路径。若用户启用尚未完成接线的路径，新模式必须显式报错，不能悄悄留下旁路。本版允许直接对sentence与mpath/m1/m3等未验证组合报不支持。

raw token的布尔mask没有可微梯度，需在实现说明中明确；开关通过反馈残差的直通梯度和独立BCE训练，不宣称梯度经过所有mask。

### 3 必须提供的诊断接口

为forward或专用方法提供 `history_override=None|0|1`。None是正常决策，0是在同一权重下完全关闭历史，1是完整开启历史。override优先于warmup、threshold和正常门控。

输出至少包含 `keep_logit`、`keep_prob`、`keep_hard`、`gate_applied`、`has_history`、各模态gamma、历史残差范数。无门模式相应字段用None或确定值，并清楚标注模式。

override只用于诊断、教师目标和测试，不能在正式推理中读取真实标签选择0或1。

必须使用原始全局索引选batch。不能截取tensor后继续使用旧history_index。对话不能跨fit/dev，任何历史跨分组边界应审计并移除不合法槽，记录数量。若数据包本来含跨对话历史，先报告数据异常，不能悄悄修成新数据后声称复现原协议。

学生只在train_fit优化，early stopping和SWA候选选择只用inner_dev。class_weight和class_prior如使用则仅从fit计算。正式valid只用于最终锁定的评估，不参与目标生成、阈值选择、epoch选择或hyperparameter sweep。

若修改既有trainer，原默认无manifest行为仍兼容；新协议所有臂必须传同一个manifest。不允许B1用全train、改进臂用90%train。

### 2 已有历史结果的使用

旧数据仅作背景，不作为新臂的配对基线。新协议训练/选择划分变化后必须重跑基线，不能拿新valid分数与旧best_valid直接做配对显著性。

本valid已在历史项目中反复使用，本方案不能宣称它是从未见过的独立确认集。新结果应写成“锁定新协议后的valid复验”；将来需要新的封存数据确认时另行安排，不在本任务打开test。

## 九 阶段六 先完成最小改动版本

这一阶段不生成效用教师，只实现旧标签代理监督下的句级门和语义辅助。便于判断少量局部修改是否已能改善乱拒。

目标为保留标签：

```text
eligible_slot = history_mask AND any_history_modality_present
keep_target = any((history_label == current_label) AND eligible_slot)
```

只对有可用历史的样本计算 `BCEWithLogitsLoss(keep_logit, keep_target)`。不能把保留目标误传给null概率，也不能把三个模态复制目标当作新的句级目标。

旧legacy_null对照继续用原代理目标和原lambda=0.1以复现旧方法；新sentence臂lambda=0.3。因此legacy与sentence的比较包含结构和辅助系数变化，不能单独归因于硬执行。后续M3/M4等对比才是控制变量的消融。

完成M3/M4的功能和inner_dev试跑后，即使提升，也不能声称标签代理已经解决所有误拒。只有同情绪与异情绪分组无法证明历史真正有益或有害。

## 十 阶段七 构造冻结的历史效用教师

### 1 教师来源和计算预算

在train_fit内按对话划成固定3折。每折教师只用另外2折训练，对被留出折生成目标。inner_dev和valid不参与教师拟合与目标生成。

3折教师统一使用B1的none模式、uniform融合、相同网络和任务配置。每折固定训练30轮，不以被留出折选epoch；用最后3轮权重平均作为固定教师。需要训练器提供固定末轮SWA保存模式，不能默认调用会按目标折选best的旧逻辑。

教师种子固定为1701、1702、1703，独立于学生10 seeds；模型eval、冻结所有参数。3份教师和效用缓存可供所有学生臂/seed共用，避免每个学生重训教师。

3折划分、教师训练轮数、末轮SWA、所有哈希先写入PROTOCOL。教师模型及缓存不因正式valid结果而重做。

### 2 目标定义

对每个被留出训练样本，在同一个冻结教师上运行两个前向：关闭全部历史和完整开启历史。

```text
loss_off = -log_softmax(logits_off)[true_class]
loss_on  = -log_softmax(logits_on)[true_class]
u = loss_off - loss_on
```

使用未加class_weight、未做label_smoothing的逐样本CE，单位nats。两次前向使用相同当前特征，不更换模型、不另采dropout。

```text
u >  0.05 : keep_target = 1
u < -0.05 : keep_target = 0
abs(u) <= 0.05 : uncertain，开关监督权重为0
weight = min(abs(u)/0.20, 1)，仅用于非uncertain且有历史样本
L_gate = sum(weight * BCEWithLogits(logit,target)) / max(sum(weight),eps)
```

当batch的sum(weight)=0时，L_gate=0且记录该情况。不得用伪造标签、全量全0/全1补齐弱监督。margin和权重尺度是本方案初始固定选择，尚未经验证。

缓存保存原始sample_index、ID、fold、u、target、weight、loss_on/off、有历史标识、教师checkpoint哈希、数据/manifest哈希和脚本版本。ID与索引共同校验，错位即报错。缺失缓存不能静默回退到label_match。

### 3 教师质量门槛

报告有益、有害、uncertain数量和类别分布，及各折u分布。不强行要求某个有害比例。

若有益/有害任一类少于有历史样本的1%，或可监督样本少于20%，先标记监督不足，检查教师是否真的使用历史、gamma/残差是否为0、override是否有效。检查仍无信号则暂停效用版扩展，交付最小版和该结果，不在valid上调delta制造信号。

教师给出的效用是参考模型效用，不能叫真实因果标签。交叉拟合减轻拟合偏差，但不保证新学生也有相同历史收益。后续必须做学生自身的反事实诊断。

## 十一 阶段八 消融矩阵

固定8个实验臂，均使用同一数据manifest、主干和训练配置。M3/M4是第一阶段最小版，E5/E6是监督升级版。

| 臂 | 名称 | 机制 | 辅助目标 | 额外语义 | 要回答的问题 |
| --- | --- | --- | --- | --- | --- |
| B0 | uniform_no_history | 完全无历史训练 | 无 | 无 | 去掉历史后整体怎样 |
| B1 | uniform_history | 原始历史注意力，无空候选 | 无 | 无 | 主基线 |
| B2 | legacy_null | 旧空候选，lambda=0.1 | 旧标签代理 | 无 | 旧方法正确开关下的表现 |
| M3 | sentence_hard_match_base | 句级硬门，lambda=0.3 | 标签代理 | 无 | 最小句级门能否工作 |
| M4 | sentence_hard_match_semantic | 与M3相同 | 标签代理 | 有 | 旧目标下语义辅助有没有用 |
| E5 | sentence_hard_utility_base | 句级硬门，lambda=0.3 | 冻结效用 | 无 | 改目标的作用 |
| E6 | sentence_hard_utility_semantic | 与E5相同 | 冻结效用 | 有 | 完整候选方案 |
| S7 | sentence_soft_utility_semantic | 软执行，lambda=0.3 | 冻结效用 | 有 | 与完整方案比较执行方式 |

B0是独立重训的无历史模型，不能用B1推理时override=0替代。B1的同权重override是另一类诊断。

预注册主对比只有 `E6-B1`。次要对比：`M4-M3`、`E5-M3`、`E6-E5`、`E6-S7`、`B2-B1`、`B1-B0`、`M4-B1`。

`E5-M3`回答“效用目标及其margin/权重机制这整个监督包的收益”，不能写成只更换了一行标签。`E6-S7`回答整个执行方式差异，包含raw token处理，不声称只测残差阈值。

如果只做了最小版，主结论只能是M4-B1的阶段性探索，不以E6名义交付结果。不得删除表现负面的消融臂。

## 十三 阶段十 机制诊断与统计

### 1 样本级记录

每个正式valid样本保存ID、seed、臂、y、预测类别、完整logits、keep_prob、keep_hard、实际执行门、has_history、有效历史数量、说话人标识和各模态残差范数。

均值概率命名 `mean_reject_probability`。二值拒绝率命名 `hard_reject_rate`。soft臂正常执行没有真正阈值断路，另报 `thresholded_reject_rate_diagnostic`，不得冒充实际硬拒绝率。

### 2 分组定义

所有臂共用相同分组成员：

- 无可用历史、有可用历史。
- 任一有效历史情绪与当前相同/无相同情绪。只命名同标签组与异标签组。
- 翻转/延续：按已核实话语时间取最近可用同说话人历史，情绪不同/相同。没有同说话人历史的样本单列unknown。旧61%来自何种定义未核实时，不强行复现为当前翻转率。
- 预测不确定性分层：由固定B1参考模型产生，边界在inner_dev确定，全部臂共用。
- 反讽：有可信现成标注才报告；否则对选定错误案例人工定性，不能把“语义高相似且异情绪”当作反讽真值。

### 3 同权重历史效用干预

对B1各seed在valid上用相同权重分别完整开/关历史，计算未平滑CE差值u。分组使用同seed的固定B1参考结果，所有比较臂共用，标签仅用于离线诊断。

- reference harmful：u < -0.05；report拒绝率及样本数。
- reference useful：u > 0.05；report误拒率及样本数。
- reference uncertain：其余；单列。

这是“B1参考有益/有害组”，不是数据固有真值。另对E6自身做同权重开/关诊断，但不能用每个臂自己的分组成员来直接比较组WF1。

报告按效用幅度加权的错决策代价，例如：有害样本仍保留时累计abs(u)，有益样本被拒时累计u。这能区分拒掉大量弱噪声与误拒少量强证据。

80%参考有害组拒率可作为描述性目标，不是强制通过线，不得以牺牲有益组为代价追指标。真正收益以总体预测和配对结果判断。

### 4 统计口径

主指标valid WF1；同步报告Macro-F1、Accuracy和未平滑CE。每臂报10seed均值、样本SD、逐seed结果。

主对比取每个seed的 `WF1_E6-WF1_B1`。95%配对CI用均值差的Student t区间：`mean +/- t_0.975,9 * SD(diff)/sqrt(10)`，10seed时临界值约2.262。判定沿用“CI不含0且至少8/10同向”，正向和负向均如实报告，零差单列。

现有 `innovation_stats.py` 用1.96近似小样本区间，函数名signflip_p实际算符号检验而非幅值符号翻转置换。新脚本须纠正并清楚命名，不原样复制这些错误。

次要预注册对比报告配对CI与配对检验p，可用枚举2^10种正负号的均值差置换，注明对差值分布对称性的假设；次要对比统一Holm校正。主对比单独预注册，不因次要结果更好而更换主指标或主对比。

若子集置信区间做bootstrap，按对话而非独立话语重采样；seed层CI与对话层CI区分命名。不能把数千句当成数千个独立重复证明机制显著。

## 十五 失败处理与停止条件

| 情况 | 执行动作 |
| --- | --- |
| 新none不能复现原始前向 | 停止所有训练，修复模式/参数/掩码差异 |
| override=0仍受历史影响 | 列出旁路，修复token mask或可选路径，重新测试 |
| gamma初始0导致误判开关有效 | 把gamma设非零再验收，检查实际残差 |
| keep_prob全0/全1 | 查目标符号、缓存索引、loss权重、数据比例及梯度，不直接调阈值 |
| 教师监督不足 | 先查断路与教师历史效用；无信号则停止效用扩展，保留负面证据 |
| 元数据或ID缺失 | 停止依赖它的步骤，报告具体缺什么，不随机造字段 |
| 无空闲GPU或权限不足 | 完成本地可做部分，记录所需资源；不占用他人任务 |
| inner_dev变差 | 仍记录结果；功能正确可完成预注册矩阵，不筛掉坏seed或坏臂 |
| 正式valid未过线 | 写未证实，不再以该valid继续刷阈值/架构 |
| E6与B0相近且几乎全拒 | 如实指出可能退化为不用历史，不能称为选择性历史利用成功 |
| 缺少反讽标注 | 只交付语义辅助机制和定性案例，不宣称反讽识别能力 |

基础复现、数据边界和断路测试属于硬门槛。开发集/valid涨分不是功能验收条件，也不能替代测试。

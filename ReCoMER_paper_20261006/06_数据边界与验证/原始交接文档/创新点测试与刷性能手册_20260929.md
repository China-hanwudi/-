# 创新点增益测试 + 刷性能手册（供重建后的会话执行）

> 前置：MHnoU 已按《MHnoU_重建指南_20260929.md》完成重建并可正常训练。
> 本手册做两件事：①测三个创新点 + 一个补充公式的增益（含创新点 2 与 3 的组合与拆解）；
> ②在赢家结构上刷性能（防过拟合协议）。所有结论以本手册实验为准。

## 第 0 步：打两个补丁

### 补丁 A：弃权机制（创新点 3）—— 本地 `abstain_setup.py` 全文
把 `abstain_setup.py` 里的补丁目标路径改成重建后的 code 目录，直接执行。

### 补丁 B：有界权重公式（创新点 2 之补充）—— 补丁全文

`n6/model.py` 的 `UGFModel.deploy_weights` 整段替换为：

```python
    def deploy_weights(self, mu: Tensor,
                       sigma: Optional[Tensor] = None) -> Tensor:
        """w = softmax(score / tau) with floor + renormalisation."""
        if self.cfg.use_m2 and sigma is not None:
            score = (mu - self.cfg.kappa * sigma) / self.cfg.tau
        else:
            score = mu / self.cfg.tau
        if getattr(self.cfg, "use_bounded_w", False):
            # 中心化有界权重：w = w0 * (1 + lambda * (r - r_bar))
            r = mu - mu.mean(dim=-1, keepdim=True)          # 中心化
            lam = float(getattr(self.cfg, "bounded_lambda", 0.3))
            w = torch.full_like(mu, 1.0 / mu.shape[-1])     # w0 = 均匀基础
            w = w * (1.0 + lam * r / (r.abs().max(dim=-1, keepdim=True).values.clamp_min(1e-6)))
            w = w.clamp_min(0.0)
            return w / w.sum(dim=-1, keepdim=True).clamp_min(1e-9)
        w = torch.softmax(score, dim=-1)
        w = w.clamp_min(self.cfg.eps_floor)
        return w / w.sum(dim=-1, keepdim=True)
```

`n6/config.py` 加：`use_bounded_w: bool = False`、`bounded_lambda: float = 0.3`；
`n6/train.py` 加 `--bounded-w`（store_true）、`--bounded-lambda`（默认 0.3）并传入 cfg；
仅 utility ∈ {gate, shapley} 时允许开启（uniform 下开启即报错）；
meta 与 FINAL_RESULT 记录 `bounded_w`、`bounded_lambda`。

## 第 1 步：实验矩阵（M3ED E2 特征包，10 seeds：7/13/17/23/29/37/43/53/71/101）

### 1.1 臂清单（公共部分：`--data <E2包> --seed <S> --out runs/<臂名>/seed<S>`）

| 臂名 | 附加开关 | 家族 | 回答什么 |
|---|---|---|---|
| uniform_h | `--utility uniform` | A 底座 | 基线（全部对比的锚） |
| uniform_nh | `--utility uniform --no-history` | A | 创新点1（闭环）在 A 家族的效应 |
| uniform_abstain | `--utility uniform --abstain` | A | 创新点3 单独 |
| gate_h | `--utility gate` | B | 门控架子参照 |
| shapley_h | `--utility shapley` | B | 创新点2 整体（架子+教师信号） |
| shapley_nh | `--utility shapley --no-history` | B | 创新点1 在 B 家族的效应 |
| shapley_bnd | `--utility shapley --bounded-w` | B | 创新点2 + 补充公式 |
| shapley_abs | `--utility shapley --abstain` | B | 组合 2+3 |
| gate_abs | `--utility gate --abstain` | B | 创新点3 装在裸架子上（拆组合用） |
| shapley_abs_bnd | `--utility shapley --abstain --bounded-w` | B | 全组合（2+3+补充） |

共 11 臂 × 10 seeds = 110 runs；shapley 臂每步要做 7 组子集实测，最慢，
全程约 5–10 分钟/run，6 卡并行约 2–3 小时。

### 1.2 预注册主对比（先锁定，后看数）

| 编号 | 对比 | 回答 |
|---|---|---|
| C1 | shapley_h − gate_h | 教师信号（创新点2 的核心部件） |
| C2 | gate_h − uniform_h | 门控架子本身 |
| C3 | shapley_bnd − shapley_h | 补充公式（有界权重） |
| C4 | uniform_abstain − uniform_h | 创新点3 单独 |
| C5 | shapley_abs − shapley_h | 组合 2+3 相对创新点2 的增量 |
| C6 | gate_abs − gate_h | 创新点3 装在裸架子上的效应 |
| C7 | shapley_h − shapley_nh | 创新点1（闭环，B 家族） |
| C8 | uniform_h − uniform_nh | 创新点1（闭环，A 家族） |
| C9 | C5 − C6（交互项） | 教师信号与弃权互相放大还是抵消 |

判定标准（锁定）：均值差 95% 配对 CI 不含 0 且 ≥8/10 种子同向 → 有用；
CI 全负且 ≥8/10 同向 → 有害；其余记"当前协议未证实"。9 个对比做 Holm 校正。

组合判读规则（锁定）：C5、C6 都正 → "2+3 一起上"；一正一负 → 拆开，报单用哪个；
都负 → 组合否决。

### 1.3 统计方法

每个对比取 10 个配对差（同种子相减），报：均值、样本 SD、95% 配对 t 区间、
exact sign-flip p（二项式：p = 2·Σ_{k≤min(wins,10−wins)} C(10,k)/2^10）、胜负种子数；
Holm-9 校正。脚本模板：本地 `innovation_stats.py`（改臂名与 ROOT 即用）。

### 1.4 工程质量检查

同一臂内 10 个种子的 valid WF1 若出现 >3σ 的离群 run，先查该 run 的
RUN_METADATA（数据哈希、代码哈希、fallback、epochs_completed），异常 run 标注后
重跑一次替换，不得静默丢弃。

## 第 2 步：刷性能（第 1 步出赢家之后执行）

### 2.1 sweep 清单（赢家臂上，3 seeds 筛查：17/29/43）

A. 训练配方旋钮（每个变体只动一个，基线为赢家配方）：
new_lr {4e-4, 1e-4}、core_lr {5e-5, 1e-5}、label_smoothing {0.0, 0.1}、
joint_kl_weight {0.0, 0.1}、epochs {48}、batch {64}、swa_window {5}、
patience {10}、weight_decay {0.05}

B. 结构相关旋钮（视赢家组成启用）：
abstain-lambda {0.05, 0.3}（赢家含弃权）、bounded-lambda {0.1, 1.0}（赢家含有界权重）、
tau {0.5, 2.0}（赢家含门控）

### 2.2 流程
Stage A（3 seeds 筛查）→ 均值不低于赢家者进 Stage B（两两组合，3 seeds）→
Stage C：Stage B 最优 vs 赢家配方，10 seeds 配对确认。

### 2.3 防过拟合五条规定（写进实验协议文件，先看后跑）
① 只用 valid 选点，test 全程封存；② 变体清单预注册，看到结果后不得追加
（追加项标 exploratory，不进主结论）；③ 按均值不按峰值；④ 最终结论必须
10 seeds 配对 CI 不含 0 且 ≥8/10 同向；⑤ 3-seed 阶段只淘汰不宣布获胜。

# 图表索引与使用建议

`02_论文图_结构与结果/v3_结构图包` 是通过绘图源码和 QA 的完整图包。每组图同时提供 SVG/PDF（投稿和后续编辑）、PNG（预览）和 TIFF（高分辨率导出）。源码、图注、设计说明、manifest 和 `qa/` 记录与图放在同一目录。

| 编号 | 文件前缀 | 建议用途 |
|---|---|---|
| 01 | `01_ReCoMER_overview` | 总体框架：MHnoU、cRBEF、local_current 的关系 |
| 02 | `02_M1_closed_loop` | 闭环历史反馈和重新评估 |
| 03 | `03_M2_contribution_router` | Shapley/贡献监督的 EvidenceRouter |
| 04 | `04_M3_history_admission` | 历史候选与空候选竞争、keep/abstain 硬断路 |
| 05 | `05_cRBEF_reference_structure` | cRBEF 专家结构 |
| 06 | `06_local_current_fusion` | 局部类别校正融合公式 |
| 07 | `07_ReCoMER_results_overview_image2_style` | 结果总览图；只填有来源的开发评估 |
| 08 | `08_ReCoMER_exact_feature_checks_image2_style` | 特征/推理一致性检查，不能当性能提升 |
| 09 | `09_ReCoMER_gate_sensitivity_image2_style` | 门控敏感性，缺失数据不要补画 |
| 10 | `10_ReCoMER_modality_pca_image2_style` | 模态表征分析，须与对应结果来源一致 |
| 11 | `11_ReCoMER_confusion_matrices_image2_style` | M3ED 混淆矩阵 |

`02_论文图_结构与结果/论文七张定稿_PNG` 是当前论文七张结构图的 PNG 预览：概念动机、总体框架、MHnoU、SABER、NCHA、cRBEF、局部类别校正。图注和结构边界以 v3 图包的文字说明为准。

修改图时优先编辑 v3 图包中的 `.py` 源码，再重新导出 SVG/PDF/PNG/TIFF 并更新 QA；不要只在 PNG 上涂改。

# Kimi 论文修改交接包

更新时间：2026-10-05（Asia/Shanghai）

这是 ReCoMER / MHnoU / cRBEF 论文的单目录交接包。目标是让 Kimi 在没有数据集本体的情况下，理解研究问题、最终代码、实验边界、论文现稿和全部论文图，并据此修改论文。

## 先读什么

1. `00_交接说明/01_给Kimi的工作指令.md`
2. `00_交接说明/02_项目事实与证据边界.md`
3. `01_论文稿件/ReCoMER_完整论文_20261005.docx` 或同名 PDF
4. `03_最终代码/README.md`、`03_最终代码/ReCoMER_补全说明.md`、`03_最终代码/ReCoMER_首轮结果说明.md`
5. `05_实验结果_汇总/` 下的 `SUMMARY.md`、`实验结论.md`、ReCoMER 元数据和消融汇总
6. `02_论文图_结构与结果/v3_结构图包/阅读说明.txt`、`图注与结构核对.txt`、`figure_manifest.json`

## 目录

- `00_交接说明`：给 Kimi 的阅读顺序、研究事实、写作边界和修改清单。
- `01_论文稿件`：最新完整稿、CVPR 版式 PDF、Introduction/Method/Experiments/Conclusion 等分章节稿。
- `02_论文图_结构与结果`：11 组结构/结果图，包含 SVG、PDF、PNG、TIFF、绘图源码、图注和 QA；另有 7 张论文定稿 PNG。
- `03_最终代码`：当前最终代码的可读源码、配置、测试和说明；排除了权重、特征缓存和 pycache。
- `04_实验脚本与协议`：训练/评估/审计脚本、门控协议和 ReCoMER 训练脚本。
- `05_实验结果_汇总`：可用于论文写作的性能摘要、逐设置 JSON、机制指标和验证审计。
- `06_数据边界与验证`：原始研究交接文档和写作证据边界。
- `07_参考材料`：EMOE 参考文本、写作提纲和代码学习笔记。

## 数据集说明

按要求没有复制任何数据集本体、`train.pt`/`valid.pt`/`test.pt`、原始媒体、样本特征缓存、预测矩阵、训练 checkpoint 或大体积 ZIP。保留了指标 JSON、实验协议、审计记录和可复现代码入口，因此 Kimi 可以据证据改写论文，但不能在此目录直接重新训练。
